# Avatar Motion Studio

Avatar Motion Studio 是一个面向人物视频创作的 Windows 桌面工具。

主要用于：

- 图生动作
- 视频人物替换
- 数字人视频生成
- 视频音轨提取
- 音频格式转换
- 本地素材管理
- 生成任务管理
- 视频结果预览与导出

当前仅提供 **Windows x64** 版本，适用于 Windows 10 / Windows 11。

---

## 1. 获取程序

推荐直接克隆仓库：

```bash
git clone https://github.com/haozheyu/avatar-motion-studio.git
```

进入目录：

```bash
cd avatar-motion-studio
```

项目发布目录结构类似：

```text
avatar-motion-studio/
├── README.md
├── LICENSE
├── avatar-motion-studio-windows-amd64.exe
│   image/
│   ├── 保存云端配置.png
│   └── 视频音频提取.png
└── tools/
    └── ffmpeg/
        └── windows/
            └── ffmpeg.exe
            └── ffprobe.exe
```

## 2. 第一次启动

进入：

```text
release-windows/
```

双击：

```text
avatar-motion-studio-windows-amd64.exe
```

即可启动程序。

首次启动时，程序会自动创建运行所需的配置和数据目录。

建议将整个项目放在普通可写目录，例如：

```text
D:\AvatarMotionStudio\
```

不要放在需要管理员权限才能写入的系统目录。

## 4. 图生动作

用于：

```text
人物图片
+
动作参考视频
↓
生成动作视频
```

适合：

- 人物动作迁移
- 舞蹈动作生成
- 动作模仿
- 短视频人物动作制作

### 使用步骤

1. 打开 **图生动作**
2. 选择人物图片
3. 选择动作参考视频
4. 设置生成参数
5. 点击生成
6. 等待任务完成
7. 在任务中心查看结果
8. 保存生成视频

### 素材建议

人物图片建议：

- 人物主体清晰
- 尽量单人
- 身体不要被严重遮挡
- 人物占画面比例不要过小
- 图片尽量清晰

动作视频建议：

- 单人动作
- 镜头稳定
- 动作连续
- 人物完整
- 避免频繁切镜

## 5. 视频换人

用于：

```text
原始视频
+
目标人物图片
↓
人物替换视频
```

适合：

- 视频角色替换
- AI 短剧
- 广告素材制作
- 人物重拍
- 视频二次创作

### 使用步骤

1. 打开 **视频换人**
2. 选择原始视频
3. 选择目标人物图片
4. 设置生成参数
5. 提交生成
6. 在任务中心等待完成
7. 预览生成结果
8. 保存视频

### 使用建议

为了获得更稳定的效果：

- 原视频尽量保持单一主体
- 避免多人长时间交叉遮挡
- 避免人物过小
- 避免快速镜头切换
- 人物正面、侧面清晰时效果通常更稳定

## 7. 视频音频提取

程序支持直接从视频中提取音轨。

可以输出：

```text
MP3
WAV
```

例如：

```text
video.mp4
↓
audio.mp3
```

或者：

```text
video.mp4
↓
audio.wav
```

操作界面：

![视频音频提取](image/视频音频提取.png)

### 使用步骤

1. 打开 **音频工具**
2. 选择 **视频提取音频**
3. 选择视频文件
4. 选择输出格式
5. 点击开始转换
6. 等待处理完成
7. 试听或保存文件

该功能在本机完成。

如果视频本身没有音轨，则无法提取声音。

    └── ffmpeg/

如果项目中已经包含对应工具，则无需额外处理。

```text

```

放入指定目录。

## 15. 常见问题

### 双击 EXE 没有反应

检查：

1. 是否已经运行了一个实例
2. Windows 是否安装 WebView2
3. 程序目录是否有写入权限
4. 配置文件是否被手动修改损坏

### 视频无法读取

检查：

```text
ffmpeg.exe
ffprobe.exe
```

是否存在。

同时确认：

- 视频文件没有损坏
- 文件路径有效
- 文件没有被其他软件锁定

### 视频生成失败

优先检查：

- API Key 是否已经配置
- 网络是否正常
- 图片是否能够正常打开
- 视频是否完整
- 人物是否清晰
- 输入素材是否符合要求

如果人物过小、遮挡严重、镜头变化过快，也可能导致生成失败。

### 一直显示生成中

可以：

1. 打开任务中心
2. 查看任务状态
3. 查看错误信息
4. 检查网络
5. 等待一段时间后重新刷新

不建议短时间内重复提交同一个任务。

### 视频没有声音

部分生成结果可能本身不带声音。

如果需要后期处理，可以使用：

```text
音频工具
```

完成：

- 音频提取
- WAV 转 MP3
- MP3 转 WAV

### 视频无法提取音频

首先确认视频本身存在音轨。

没有音轨的视频无法提取声音。

## 17. 使用建议

为了获得更稳定的生成结果，建议素材满足以下条件：

### 图片

- 清晰
- 人物主体明显
- 尽量单人
- 避免大面积遮挡
- 分辨率不要过低

### 视频

- 人物清晰
- 动作连续
- 镜头稳定
- 避免频繁切镜
- 避免严重运动模糊

### 音频

- 人声清晰
- 噪声较少
- 音量正常
- 避免严重爆音
